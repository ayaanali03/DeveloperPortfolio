## 4. Personal Project – Student Task and Assignment Manager

### Project Overview

I plan to develop a Student Task and Assignment Manager that helps students organise academic work, track deadlines and manage daily study tasks.

The project addresses a common problem: students often manage assignments, submissions, tests and personal tasks across different platforms or manually maintained lists.

### Proposed Features

- Add, edit and delete assignments.
- Set submission deadlines and priorities.
- Organise tasks by subject.
- Track completed and pending work.
- Display upcoming deadlines.
- Provide a dashboard showing task progress.
- Store user data in a database.
- Support user accounts and authentication in a later version.

### Planned Technology Stack

| Component | Technology |
|---|---|
| Frontend | HTML, CSS and JavaScript |
| Advanced Frontend | React |
| Backend | Python Flask or Node.js |
| Database | MySQL or PostgreSQL |
| Version Control | Git and GitHub |
| Deployment | Suitable cloud hosting platform |

### Development Milestones

**Phase 1 – Planning and Design**
- Identify essential features.
- Design the application layout.
- Create the GitHub repository.

**Phase 2 – Frontend Development**
- Build the dashboard.
- Create task and assignment forms.
- Add task lists and status indicators.

**Phase 3 – Backend and Database**
- Develop the backend API.
- Connect the database.
- Implement task creation, editing and deletion.

**Phase 4 – Testing and Deployment**
- Test the main features.
- Fix errors and improve usability.
- Deploy the application and document the project.

**Expected outcome:** A functional student productivity application demonstrating frontend development, backend programming, database integration and software engineering skills.
